# groupe des permutations
groupe des permutations

Le programme 
graphedespermuts.py

construit les graphes de permutations pour n éléments, et permet de visualiser dans Graphviz. Après, faut régler les paramètres. La commande : 
neato -Tpdf permuts6.dot -o permu6.pdf -Gstart=rand -Gepsilon=0.00001 -Gsplines=true -Gsep=0.1  -Goverlap="prism50" -Goverlap_scaling=-10 -Gdamping=0.1
donne des résultats à peu près potables. A creuser.
